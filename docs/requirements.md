# 需求规格说明书

## 项目名称

LeafNeko Windows 必装软件部署工具（LeafNeko DeployTool）

## 项目概述

一款 Windows 桌面工具（单文件便携 EXE），帮助用户在新装系统后快速部署常用软件。从 Gitee 云端仓库拉取清单和便携应用，支持一键安装全部 / 逐个选择安装。

## 用户故事

- 作为普通用户，我希望在新装 Windows 系统后，打开一个软件就能把常用软件一键装好，不用一个一个去官网找
- 作为普通用户，我希望看到清晰的软件列表，知道有哪些软件可以装
- 作为普通用户，我希望可以选择装哪些、不装哪些
- 作为维护者（LeafNeko），我希望通过一个简单的文本文件就能管理软件清单，方便更新维护

## 功能需求

### FR-01: 许可协议
- 首次启动显示许可协议页面
- 用户必须点击「同意」才能使用软件
- 不同意则退出程序
- 同意后记录到本地配置，下次不再显示

### FR-02: 云端清单拉取
- 启动后自动从 Gitee 仓库下载 `app-list.txt`
- 解析清单文件，提取软件名称、下载直链、分类

### FR-03: 软件列表展示
- 以卡片网格形式展示所有软件
- 每张卡片显示：软件名称、分类、安装状态
- 支持按分类标签过滤（全部/浏览器/压缩工具等）
- 每张卡片可独立勾选/取消勾选

### FR-04: 便携应用部署
- 作为独立功能卡片，用户手动点击触发
- 从 Gitee 仓库下载 `portable-apps.zip`
- 解压到 `C:\` 根目录
- 显示解压进度条

### FR-05: 快捷方式部署
- 作为独立功能卡片，用户手动点击触发
- 从 Gitee 仓库下载 `shortcuts.zip`
- 解压到当前用户桌面（自适应路径）
- 显示解压进度条

### FR-06: 一键安装
- 底部「全选」按钮，一键选中所有软件
- 底部「一键安装已选」按钮，批量安装已勾选的软件
- 显示已选数量（如"已选 3/8"）

### FR-07: 下载安装
- 创建临时目录 `%TEMP%\LeafNeko-DeployTool\<软件名>\`
- 下载安装包，显示下载进度条
- 下载完成后自动运行安装程序（exe/msi）
- 支持多进度条（单文件进度 + 总体进度）

### FR-08: 版本检测
- 用户可手动触发版本检测
- 查询 Windows 注册表判断软件是否已安装
- 在卡片上显示「已安装/未安装」状态

### FR-09: 缓存清理
- 安装全部完成后，自动删除临时目录中的所有安装包
- 每次下载都是全新下载，不保留旧文件

### FR-10: 错误处理
- 下载失败时显示错误提示
- 解压失败时显示错误提示
- 不影响其他软件的正常安装

## 非功能需求

### NFR-01: 性能
- 软件启动时间不超过 3 秒
- UI 操作响应时间不超过 200ms
- 下载进度条刷新间隔不超过 500ms

### NFR-02: 兼容性
- 支持 Windows 10 / Windows 11
- 支持 64 位系统

### NFR-03: 可用性
- 界面简洁直观，普通用户无需学习即可使用
- 所有操作有明确的视觉反馈

### NFR-04: 安全性
- 管理员权限仅用于向 C 盘写入文件
- 下载的安装包在临时目录中运行，不影响系统其他部分

## 云端仓库规范

仓库地址：`https://gitee.com/LeafNeko-QwQ/zip-deploy-manifest`

### 文件清单

| 文件名 | 用途 | 格式 |
|--------|------|------|
| `app-list.txt` | 安装版软件清单 | UTF-8 文本 |
| `portable-apps.zip` | 便携/免安装应用集合 | ZIP 压缩包 |
| `shortcuts.zip` | 便携应用的快捷方式 | ZIP 压缩包 |

### 清单文件格式

```txt
# 注释行（以 # 开头）
软件名称|下载直链|分类
```

- 编码：UTF-8
- 分隔符：`|`（竖线）
- 字段：名称、直链、分类
- 空行和 `#` 开头行忽略
