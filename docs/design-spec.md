# UI/UX 设计规范

## 设计理念

- **简洁直观**：用户无需学习，打开即懂
- **视觉舒适**：淡粉色系，柔和护眼
- **动效自然**：动画不生硬，符合物理直觉

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#F8A5B2` | 淡粉色，用于按钮、标签选中态、进度条 |
| 浅主色 | `#FFB6C1` | 更浅粉色，hover 状态 |
| 背景 | `#FFF5F7` | 极浅粉色窗口背景 |
| 卡片背景 | `#FFFFFF` | 纯白卡片 |
| 卡片阴影 | `#1A000000` | 10% 黑色，卡片投影 |
| 卡片Hover阴影 | `#26000000` | 15% 黑色，hover 加深 |
| 文字主色 | `#3D3D3D` | 深灰，正文 |
| 文字辅助 | `#9E9E9E` | 浅灰，分类/提示 |
| 成功色 | `#66BB6A` | 绿色，已安装/完成 |
| 错误色 | `#EF5350` | 红色，错误提示 |
| 强调色 | `#FF80AB` | 深粉色，选中态边框 |

## 布局规范

### 窗口尺寸
- 默认：1100 × 750
- 最小：900 × 600
- 支持最大化

### 布局比例
```
+──────────────────────────────────────────────────────+
|  顶部品牌栏：高度 56px，水平内边距 24px              |
+──────────────────────────────────────────────────────+
|  分类标签栏：高度 48px，水平内边距 24px              |
+──────────────────────────┬───────────────────────────+
|  左侧卡片网格区          │  右侧功能卡片区           |
|  宽度占比 65%            │  宽度占比 35%             |
|  内边距 24px             │  内边距 24px              |
|  卡片间距 16px           │  卡片间距 16px            |
|  卡片最小宽度 220px      │  固定宽度 320px           |
+──────────────────────────┴───────────────────────────+
|  底部操作栏：高度 64px，水平内边距 24px              |
+──────────────────────────────────────────────────────+
```

### 圆角规范
- 窗口：8px
- 卡片：12px
- 按钮：8px
- 进度条：4px
- 标签：16px（胶囊形）

### 间距规范
- 内容区块间距：24px
- 卡片间距：16px
- 元素内部间距：12px
- 图标与文字间距：8px

## 组件规范

### 软件卡片 (AppCard)
```
┌──────────────────────────────────┐
│  [图标 48x48]                    │
│                                  │
│  软件名称                        │
│  分类标签                        │
│                                  │
│  [状态标识]          [☑️ 勾选]   │
└──────────────────────────────────┘
```
- 宽度：自适应（最小 220px）
- 高度：160px
- 背景：白色
- 圆角：12px
- 阴影：0 2px 8px rgba(0,0,0,0.1)
- hover：上移 4px，阴影加深

### 功能卡片 (ActionCard)
```
┌──────────────────────────────────┐
│  [图标 32x32]  功能名称          │
│                                  │
│  功能描述文字                    │
│                                  │
│  ┌────────────────────────────┐  │
│  │        [执行按钮]          │  │
│  └────────────────────────────┘  │
│                                  │
│  (执行后显示迷你进度条)         │
│  ████████████░░░ 75%           │
└──────────────────────────────────┘
```
- 宽度：320px（固定）
- 高度：自动
- 圆角：12px
- 背景：白色

### 分类标签 (CategoryTab)
```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│    全部 ✓    │  │    浏览器    │  │   压缩工具   │
└──────────────┘  └──────────────┘  └──────────────┘
```
- 选中态：主色背景 + 白色文字
- 未选中：透明背景 + 灰色文字
- 圆角：16px（胶囊形）
- hover：浅粉色背景过渡

### 按钮
```
┌─────────────────────┐  ┌─────────────────────┐
│     ☑️  全选        │  │  ⬇️  一键安装 (3个)  │
└─────────────────────┘  └─────────────────────┘
```
- 主按钮：主色背景 + 白色文字
- 次按钮：主色边框 + 主色文字 + 透明背景
- 圆角：8px
- 最小宽度：120px
- 高度：40px
- 禁止态：灰色背景 + 灰色文字

### 进度条 (AnimatedProgressBar)
```
┌──────────────────────────────────────┐
│  ████████████████░░░░░░░░░░  75%    │
│  (渐变色从左到右流动动画)           │
└──────────────────────────────────────┘
```
- 高度：8px
- 背景：`#F0F0F0`
- 填充：主色到强调色线性渐变
- 动画：流动 shimmer 效果（持续）
- 圆角：4px

## 动画规范

| 动画 | 属性 | 时长 | 缓动函数 |
|------|------|------|----------|
| 窗口淡入 | Opacity 0→1 | 300ms | EaseOutCubic |
| 卡片入场 | TranslateY +30→0, Opacity | 400ms | EaseOutBack |
| 卡片交错 | 每张延迟 50ms | - | - |
| 卡片Hover | Scale 1→1.03, Shadow | 200ms | EaseOutQuad |
| 卡片Hover恢复 | Scale 1.03→1, Shadow | 200ms | EaseInQuad |
| 按钮涟漪 | Scale 0→2, Opacity | 600ms | EaseOutCubic |
| 标签切换 | 背景色过渡 | 200ms | EaseInOutQuad |
| 进度条填充 | Width 动画 | 300ms | EaseOutQuad |
| 进度条流光 | GradientStop Offset | 1500ms | Linear(循环) |
| 完成对勾 | Scale 0→1.2→1 | 400ms | EaseOutBack |
| 错误闪烁 | BorderBrush 红→透明 | 500ms | EaseInOutQuad |
| 数字跳动 | 数值变化动画 | 300ms | EaseOutQuad |
