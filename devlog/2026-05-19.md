# 开发日志 — 2026-05-19

## 第十九轮 — 日志上传文件锁修复 + 仓库 URL 修复

### Bug 修复

- [x] **日志摘要失败 / 日志上传失败** ("The process cannot access the file because it is being used by another process")
  - **根因**: `LoggerService.Init()` 中 `TextWriterTraceListener(CurrentLogFile)` 内部用 `FileShare.Read` 打开写入流。下游 `GetLogSummary()` 调用 `File.ReadAllLines()` 和 `LogUploadService.UploadFileAsync()` 调用 `File.ReadAllTextAsync()` 也用 `FileShare.Read` 打开读取流。写入方允许他人读，但读取方不允许他人写 → OS 拒绝打开
  - **修复**:
    1. `Init()` — 手动创建 `FileStream(FileShare.ReadWrite)` 再传给 `TextWriterTraceListener`
    2. `GetLogSummary()` — 新增 `CountLinesSafe()` 用 `FileShare.ReadWrite` 统计行数
    3. `LogUploadService.UploadFileAsync()` — 新增 `ReadAllTextSafeAsync()` 用 `FileShare.ReadWrite` 读取内容

- [x] **仓库测速 404 + 自更新检查 404** ("Response status code does not indicate success: 404")
  - **根因**: `RepoService.BaseUrl` 指向 `/raw/main/`，但 Gitee 仓库实际文件在 `master` 分支（原 `main` 分支为空或不存在）。CLAUDE.md 明确记载分支为 `master`
  - **修复**: `BaseUrl` 中 `main` → `master`

- [x] **版本号** 1.0.14 → 1.0.15
