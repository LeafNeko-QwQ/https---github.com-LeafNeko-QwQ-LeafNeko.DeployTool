## 2026-05-16 第六轮修复 — 下载稳定性 + ZIP中文编码 + 全选状态同步

- [x] **Fix 1: 便携应用下载"响应提前结束"**
  - `RepoService.RetryAsync` 新增 `IOException` 捕获（连接中断/响应提前结束）
  - `HttpRequestException` 重试条件新增 `StatusCode == null`（无状态码的网络错误）
  - 所有可重试错误统一 3 次指数退避（1s/2s/4s）

- [x] **Fix 2: 快捷方式中文文件名乱码**
  - 根因：ZIP 文件在中文 Windows 上创建时使用 GBK 编码，.NET 默认以 UTF-8 解码导致乱码
  - `App.xaml.cs` 注册 `CodePagesEncodingProvider` 以启用 GBK（Code Page 936）
  - `DeployService.ExtractZipWithProgressAsync` 改为编码感知：
    - `DetectZipEncoding()`：先以 UTF-8 打开 ZIP，检查条目名是否包含替换字符 `�`
    - 若有替换字符 → 回退到 GBK 编码
    - `ExtractEntries()`：使用正确编码的 `ZipArchive` 构造函数提取文件

- [x] **Fix 3: 单卡点击后全选按钮状态不同步**
  - 根因：`AppItemViewModel.IsSelected` 变化时不通知 `MainViewModel`
  - `MainViewModel.LoadFromList()` 现在为每个 `AppItemViewModel` 订阅 `PropertyChanged`
  - `OnAppItemPropertyChanged()` 在 `IsSelected` 变化时调用 `UpdateSelectionCount()`
  - 从而触发 `IsAllSelected` 重新计算 → 按钮文字自动更新

- [x] **构建通过** — dotnet build 0 错误 0 警告；dotnet publish 单文件 EXE 成功
