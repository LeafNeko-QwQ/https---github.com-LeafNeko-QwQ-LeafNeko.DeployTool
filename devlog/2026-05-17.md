## 第八轮 — 动画重写 + 应用图标 + 配置模板 + 更新历史

### 动画重写（CSS 风格平滑过渡）

- [x] **架构重构：单帧游戏循环替代多路 DispatcherTimer**
  - 旧：3 个独立 DispatcherTimer（悬停/回归/弹跳各一个），状态机复杂
  - 新：`CompositionTarget.Rendering` 单帧循环驱动所有平滑过渡
  - 目标值/当前值架构：鼠标设置目标，每帧向目标值插值

- [x] **悬停→离开的平滑过渡**
  - 所有属性（缩放/倾斜/平移/阴影/辉光）同时向目标值插值
  - 类似 CSS `transition: all 300ms ease-out`
  - 悬停跟随速度 0.10，回归速度 0.06（返回更慢，更优雅）

- [x] **入场动画**
  - `Loaded` 事件触发弹入动画：0.82 → 1.0（BackEase, Amplitude=0.35, 480ms）
  - 卡片加载时从缩小状态弹入，类似 iOS SpringBoard 效果

- [x] **点击弹跳动画（SplineKeyFrame）**
  - 旧：手动 DispatcherTimer + 分段正弦函数
  - 新：WPF `DoubleAnimationUsingKeyFrames` + 4 个 `SplineDoubleKeyFrame`
  - 动画曲线：0ms 压入(0.88) → 140ms 过冲(1.07) → 270ms 回弹(0.97) → 420ms 静止(1.0)
  - 使用 `KeySpline` 自定义贝塞尔曲线，类似 CSS `@keyframes` + `cubic-bezier()`
  - Storyboard 独立于游戏循环（`_isBouncing` 标志隔离）

- [x] **视觉参数微调**
  - 最大倾斜角 3° → 5°（更明显的 3D 效果）
  - 悬停缩放 1.03 → 1.04
  - 阴影模糊 8→14（悬停）/ 12→14
  - 阴影深度 2→4

- [x] **被移除的代码**
  - `_returnTimer` / `_bounceTimer` DispatcherTimer 状态机
  - `OnReturnTick` / `OnBounceTick` / `BounceEase` / `CubicEaseOut`
  - `StopReturnTimer` / `_isAnimatingBack` / `_from*` 快照字段
